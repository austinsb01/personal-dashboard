# specs

Approved feature design documents. Each spec captures the problem, the decisions
made during brainstorming, the data model, behavior, module structure, testing,
and build order for one feature. A spec is reviewed and approved before its
implementation plan is written.

- `2026-07-06-meal-prep-ingredient-grouping-design.md` — reusable recipes, log a
  recipe to a day, and a weekly meal-prep view with an ingredient rollup.
